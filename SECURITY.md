# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/kgr88/bosectl_gui/security/advisories/new).
Include the steps to reproduce the problem and the bosectl version.

You get an answer as soon as possible. When a fix is ready, the release notes
credit you, unless you ask not to be named.
